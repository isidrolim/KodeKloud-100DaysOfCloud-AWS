# 100 Days of Cloud AWS - Day 009: Enable Termination Protection for EC2 Instance

## Scenario

As part of the AWS migration, the Nautilus DevOps team identified an existing EC2 instance that was created without termination protection.

To reduce the risk of accidental deletion, termination protection needs to be enabled on the instance.

## Requirement

Configure the existing EC2 instance with the following settings:

- **Instance Name:** `devops-ec2`
- **Region:** `us-east-1`
- **Termination Protection:** Enabled

## Implementation

### Step 1: Open the EC2 Console

1. Sign in to the **AWS Management Console**.
2. Make sure the selected region is:

```text
N. Virginia (us-east-1)
```

3. Search for and open **EC2**.
4. Navigate to:

```text
Instances → Instances
```

5. Locate and select:

```text
devops-ec2
```

### Step 2: Verify the Correct Instance

Before making the change, confirm:

```text
Instance Name: devops-ec2
Region:        us-east-1
```

This ensures termination protection is being applied to the correct EC2 resource.

### Step 3: Enable Termination Protection

With `devops-ec2` selected:

1. Click **Actions**.
2. Select **Instance settings**.
3. Select **Change termination protection**.
4. Enable:

```text
Termination protection
```

5. Click **Save**.

## Validation

Verify the setting by selecting:

```text
Actions → Instance settings → Change termination protection
```

Confirm that termination protection shows:

```text
Enabled
```

Final configuration:

```text
Instance:                devops-ec2
Region:                  us-east-1
Termination Protection:  Enabled
```

## Result

✅ EC2 instance `devops-ec2` identified.

✅ Termination protection successfully enabled.

✅ Instance protected against accidental termination through normal EC2 termination operations.

✅ Challenge successfully completed and validated.

## Key Takeaway

**Termination Protection** is an EC2 safeguard designed to prevent an instance from being accidentally terminated.

It is different from **Stop Protection**:

```text
Stop Protection
└── Prevents accidental stopping of the instance

Termination Protection
└── Prevents accidental termination of the instance
```

Stopping an EC2 instance is normally reversible because the instance can be started again.

Terminating an EC2 instance permanently removes the instance, making termination protection particularly important for critical workloads.

In production, termination protection should be combined with additional safeguards such as **IAM least privilege, backups, EBS snapshots, monitoring, and formal change-control procedures**.
