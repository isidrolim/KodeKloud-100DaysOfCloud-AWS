# 100 Days of Cloud AWS - Day 006: Launch EC2 Instance

## Scenario

The Nautilus DevOps team is continuing its incremental migration to AWS. For this task, an Amazon EC2 instance needs to be deployed with the required compute, operating system, key pair, and security group configuration.

## Requirement

Launch an EC2 instance with the following configuration:

- **Instance Name:** `datacenter-ec2`
- **AMI:** Amazon Linux
- **Instance Type:** `t2.micro`
- **Key Pair:** Create a new RSA key pair named `datacenter-kp`
- **Security Group:** Default security group
- **Region:** `us-east-1`

## Implementation

### Step 1: Open the EC2 Console

1. Sign in to the **AWS Management Console**.
2. Make sure the selected region is **N. Virginia (`us-east-1`)**.
3. Search for and open **EC2**.
4. Go to **Instances → Instances**.
5. Click **Launch instances**.

### Step 2: Configure the Instance Name

Under **Name and tags**, enter:

```text
datacenter-ec2
```

### Step 3: Select the AMI

Under **Application and OS Images (Amazon Machine Image)**:

1. Select **Amazon Linux**.
2. Keep the available Amazon Linux AMI selected.

### Step 4: Select the Instance Type

Under **Instance type**, select:

```text
t2.micro
```

### Step 5: Create the Key Pair

Under **Key pair (login)**:

1. Click **Create new key pair**.
2. Enter:

```text
Key pair name: datacenter-kp
Key pair type: RSA
```

3. Create the key pair.
4. Store the downloaded private key securely.

> The private key should not be committed to GitHub or any source-control repository.

### Step 6: Configure the Security Group

Under **Network settings**:

1. Click **Edit** if necessary.
2. Choose **Select existing security group**.
3. Select the security group named:

```text
default
```

Do not create a new security group for this challenge.

### Step 7: Launch the Instance

Review the configuration:

```text
Name:           datacenter-ec2
AMI:            Amazon Linux
Instance Type:  t2.micro
Key Pair:       datacenter-kp
Key Type:       RSA
Security Group: default
Region:         us-east-1
```

Click **Launch instance**.

## Validation

Navigate to:

**EC2 → Instances**

Select `datacenter-ec2` and verify:

- **Instance state:** Running
- **Name:** `datacenter-ec2`
- **Instance type:** `t2.micro`
- **Platform/AMI:** Amazon Linux
- **Key pair:** `datacenter-kp`
- **Security group:** `default`

Also navigate to:

**EC2 → Network & Security → Key Pairs**

Verify:

```text
Name: datacenter-kp
Type: RSA
```

## Result

✅ EC2 instance `datacenter-ec2` successfully launched.

✅ Amazon Linux used as the operating system.

✅ Instance type configured as `t2.micro`.

✅ RSA key pair `datacenter-kp` created and associated.

✅ Default security group attached.

✅ Instance deployed in `us-east-1`.

## Key Takeaway

Launching an EC2 instance brings several AWS components together:

**AMI → Instance Type → Network/VPC → Security Group → Key Pair → EC2 Instance**

The **AMI** determines the starting operating system, the **instance type** determines compute resources, the **security group** controls network traffic, and the **key pair** provides SSH authentication.

In production, always verify the security rules of an existing security group before attaching it rather than assuming that a group named `default` provides the required or appropriate access.
