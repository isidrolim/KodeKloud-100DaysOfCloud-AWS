# 100 Days of Cloud AWS - Day 014: Terminate EC2 Instance

## Scenario

During the AWS migration, several resources were created that are no longer required.

As part of resource cleanup, the Nautilus DevOps team needs to terminate an unused EC2 instance and confirm that it reaches the **Terminated** state.

## Requirement

Terminate the existing EC2 instance with the following requirements:

- **EC2 Instance:** `nautilus-ec2`
- **Region:** `us-east-1`
- **Final Instance State:** `Terminated`

## Implementation

### Step 1: Open the EC2 Console

1. Sign in to the **AWS Management Console**.
2. Make sure the selected region is:

```text
N. Virginia (us-east-1)
```

3. Search for and open **EC2**.
4. Navigate to:

```text
Instances → Instances
```

### Step 2: Identify the Correct Instance

Locate:

```text
nautilus-ec2
```

Before terminating anything, verify that this is the correct resource.

Check:

```text
Instance Name
Instance ID
Instance State
Region
```

> Instance termination is destructive. In production, always verify the instance ID, application dependencies, backups, attached storage, and termination protection before proceeding.

### Step 3: Terminate the Instance

Select:

```text
nautilus-ec2
```

Then:

1. Click **Instance state**.
2. Select **Terminate (delete) instance**.
3. Review the instance being terminated.
4. Click **Terminate (delete)** to confirm.

### Step 4: Wait for Termination

The instance state will transition through:

```text
Running
   │
   ▼
Shutting-down
   │
   ▼
Terminated
```

Do not submit the challenge while the instance is still:

```text
Shutting-down
```

Wait until the state becomes:

```text
Terminated
```

## Validation

Navigate to:

```text
EC2 → Instances
```

Locate `nautilus-ec2` and verify:

```text
Instance Name:   nautilus-ec2
Instance State:  Terminated
Region:          us-east-1
```

The original success criteria are satisfied when:

- The correct `nautilus-ec2` instance has been terminated.
- The instance state shows `Terminated`.

## Result

✅ EC2 instance `nautilus-ec2` identified.

✅ Correct instance verified before deletion.

✅ EC2 termination initiated successfully.

✅ Instance state verified as `Terminated`.

✅ Challenge successfully completed and validated.

## Key Takeaway

**Stopping** and **terminating** an EC2 instance are fundamentally different operations:

```text
STOP
EC2 Instance
    │
    ▼
Stopped
    │
    └── Can normally be started again


TERMINATE
EC2 Instance
    │
    ▼
Shutting-down
    │
    ▼
Terminated
    │
    └── Cannot be started again
```

Termination should therefore be treated as a **destructive production change**.

Before terminating a production EC2 instance, verify:

```text
Correct Instance
      ↓
Application Dependencies
      ↓
Backups / AMI / Snapshots
      ↓
Attached EBS Volumes
      ↓
Termination Protection
      ↓
Terminate
      ↓
Verify Terminated
```

Also remember that terminating an EC2 instance does not automatically mean every related AWS resource is deleted. Depending on their configuration, resources such as **EBS volumes, Elastic IPs, snapshots, ENIs, and other dependencies** may remain and should be reviewed separately during cleanup.
