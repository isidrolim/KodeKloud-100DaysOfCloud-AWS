# 100 Days of Cloud AWS - Day 003: Create Subnet via AWS CLI

## Scenario

The Nautilus DevOps team is continuing its incremental migration to AWS. For this task, a new subnet must be created inside the **default VPC**.

## Requirement

Create a subnet with the following configuration:

- **Subnet Name:** `devops-subnet`
- **VPC:** Default VPC
- **Region:** `us-east-1`

## Implementation

First, retrieve the default VPC ID:

```bash
VPC_ID=$(aws ec2 describe-vpcs \
  --filters "Name=is-default,Values=true" \
  --query "Vpcs[0].VpcId" \
  --output text)

echo $VPC_ID
```

Check the existing subnets and CIDR ranges in the default VPC before choosing a new CIDR:

```bash
aws ec2 describe-subnets \
  --filters "Name=vpc-id,Values=$VPC_ID" \
  --query "Subnets[*].[SubnetId,CidrBlock,AvailabilityZone]" \
  --output table
```

Choose a **non-overlapping CIDR block** within the default VPC CIDR.

Create the subnet:

```bash
SUBNET_ID=$(aws ec2 create-subnet \
  --vpc-id $VPC_ID \
  --cidr-block <AVAILABLE-CIDR> \
  --query "Subnet.SubnetId" \
  --output text)

echo $SUBNET_ID
```

Add the required `Name` tag:

```bash
aws ec2 create-tags \
  --resources $SUBNET_ID \
  --tags Key=Name,Value=devops-subnet
```

## Validation

Verify the subnet:

```bash
aws ec2 describe-subnets \
  --subnet-ids $SUBNET_ID \
  --query "Subnets[*].[SubnetId,VpcId,CidrBlock,AvailabilityZone,Tags[?Key=='Name'].Value|[0]]" \
  --output table
```

Confirm that:

- The subnet belongs to the **default VPC**.
- The CIDR does not overlap an existing subnet.
- The `Name` tag is `devops-subnet`.

## Result

✅ Subnet `devops-subnet` created successfully.

✅ Subnet created inside the default VPC.

✅ A non-overlapping CIDR range was used.

✅ Challenge successfully completed and validated.

## Key Takeaway

A subnet's CIDR must be contained within its VPC CIDR and **must not overlap with another subnet in the same VPC**.

Also, `devops-subnet` is not the AWS subnet resource ID—it is a **Name tag**. The actual AWS resource is identified by a value such as `subnet-xxxxxxxxxxxxxxxxx`.
