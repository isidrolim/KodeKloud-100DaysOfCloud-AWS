# 100 Days of Cloud AWS - Day 008: Enable Stop Protection for EC2 Instance

## Scenario

As part of the AWS migration, the Nautilus DevOps team needs to protect an existing EC2 instance from being accidentally stopped.

AWS provides **Stop Protection** to prevent users from stopping an instance through normal EC2 stop operations.

## Requirement

Configure the existing EC2 instance with the following settings:

- **Instance Name:** `nautilus-ec2`
- **Region:** `us-east-1`
- **Stop Protection:** Enabled

## Implementation

### Step 1: Open the EC2 Console

1. Sign in to the **AWS Management Console**.
2. Make sure the selected region is:

```text
N. Virginia (us-east-1)
```

3. Search for and open **EC2**.
4. Navigate to:

```text
Instances → Instances
```

5. Locate and select:

```text
nautilus-ec2
```

### Step 2: Verify the Correct Instance

Before making any changes, confirm that the selected instance is:

```text
Name:   nautilus-ec2
Region: us-east-1
```

This ensures the protection setting is applied to the correct resource.

### Step 3: Enable Stop Protection

With `nautilus-ec2` selected:

1. Click **Actions**.
2. Select **Instance settings**.
3. Select **Change stop protection**.
4. Enable:

```text
Stop protection
```

5. Click **Save**.

## Validation

With `nautilus-ec2` selected:

1. Open **Actions → Instance settings → Change stop protection**.
2. Verify that stop protection is:

```text
Enabled
```

The original success criteria are now satisfied:

```text
Instance:         nautilus-ec2
Region:           us-east-1
Stop Protection:  Enabled
```

## Result

✅ EC2 instance `nautilus-ec2` identified.

✅ Stop protection successfully enabled.

✅ Instance protected against accidental stop operations.

✅ Challenge successfully completed and validated.

## Key Takeaway

**Stop Protection** helps prevent accidental interruption of an EC2 instance by blocking normal attempts to stop it.

It is important to distinguish between the two EC2 protection mechanisms:

```text
Stop Protection        → Protects against accidental instance stops
Termination Protection → Protects against accidental instance termination
```

These controls are useful safeguards for important workloads, but they are not substitutes for proper IAM permissions, change management, monitoring, backups, and high-availability architecture.
